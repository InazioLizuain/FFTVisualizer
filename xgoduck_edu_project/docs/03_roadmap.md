# 03 - Roadmap por hitos

## Hito 0 - Preparación
- [ ] Validación legal/técnica completada
- [ ] Referencias congeladas
- [ ] BOM consolidado con alternativas

## Hito 1 - Bring-up de placa
- [ ] Alimentación estable
- [ ] Programación firmware mínima
- [ ] Telemetría básica

## Hito 2 - Actuadores y sensores
- [ ] Control de actuadores estable
- [ ] Lectura IMU/sensores consistente
- [ ] Gestión de errores de hardware

## Hito 3 - Locomoción básica
- [ ] Secuencias básicas reproducibles
- [ ] Ajuste inicial de parámetros
- [ ] Checklist de seguridad mecánica

## Hito 4 - Runtime avanzado
- [ ] Integración de módulos de control
- [ ] Pipeline de comandos/estados
- [ ] Logging y diagnóstico

## Hito 5 - Entrenamiento y evaluación
- [ ] Captura de dataset
- [ ] Entrenamiento reproducible
- [ ] Métricas y comparación de iteraciones
