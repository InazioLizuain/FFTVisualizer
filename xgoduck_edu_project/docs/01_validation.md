# 01 - Validación previa

## 1) Licencias y alcance legal
- [ ] Revisar licencias de repositorios de referencia.
- [ ] Confirmar compatibilidad con uso educativo y redistribución.
- [ ] Definir qué contenido se replica, referencia o reescribe desde cero.

## 2) Riesgos técnicos principales
- [ ] Componentes del BOM descontinuados.
- [ ] Versiones de firmware/librerías incompatibles.
- [ ] Calibración mecánica no reproducible.
- [ ] Falta de artefactos/modelos de entrenamiento exactos.

## 3) Criterio de éxito inicial
- [ ] Arranque de placa (boot + comunicación básica).
- [ ] Lectura de sensores clave.
- [ ] Control estable de actuadores.
- [ ] Ejecución de comportamiento básico y repetible.
