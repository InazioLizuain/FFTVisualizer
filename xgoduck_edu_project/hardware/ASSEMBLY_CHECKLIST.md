# Assembly Checklist

## Antes de alimentar
- [ ] Verificación visual de soldaduras/conectores
- [ ] Continuidad de líneas críticas
- [ ] Polaridad correcta en alimentación

## Primer encendido
- [ ] Fuente limitada en corriente
- [ ] Medición de voltajes esperados
- [ ] Temperatura normal en componentes

## Verificación funcional
- [ ] Comunicación con placa estable
- [ ] Sensores responden
- [ ] Actuadores responden sin bloqueos

## Seguridad
- [ ] Parada de emergencia definida
- [ ] Zona de pruebas segura
- [ ] Procedimiento de apagado documentado
